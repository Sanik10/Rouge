## 📝 ЧЕТЫРЕ КРИТИЧЕСКИХ МОМЕНТА

### 1. FirstHitIgnored должен быть вызван ПЕРЕД takeDamage()

```java
// ✅ ПРАВИЛЬНО
int dmg = enemy.getSpecial().onBeforeTakeDamage(enemy, damage);
enemy.takeDamage(dmg);

// ❌ НЕПРАВИЛЬНО
enemy.takeDamage(damage);  // ← FirstHitIgnored не будет вызван!
```

Это почему:
```
takeDamage() вызывает:
  → special.onBeforeTakeDamage()  ← ЗДЕСЬ FirstHitIgnored срабатывает!
  → hp = Math.max(0, hp - actual)
```

**Ты это уже правильно сделал в Enemy.takeDamage()!** ✓

---

### 2. Player и enemies ДОЛЖНЫ быть в GameState

**Текущая архитектура:**
```
DefaultGameEngine
  ├─ GameState (playerX, playerY)
  ├─ Player (отдельно) ← проблема!
  └─ List<Enemy> (отдельно) ← проблема!
```

**Должна быть:**
```
DefaultGameEngine
  └─ GameState
      ├─ Player
      └─ List<Enemy>
```

Почему?
- ✅ Состояние игры в одном месте
- ✅ Боевая система имеет полный контекст
- ✅ Проще синхронизировать (player.x = playerX)
- ✅ Безопаснее (меньше inconsistency)

---

### 3. afterPlayerTurn() → enemiesTurn() порядок ВАЖЕН

```java
if (playerActionUsedTurn) {
    state.afterPlayerTurn(log);  // ← ПЕРВЫЙ: обновить игрока
    state.enemiesTurn(log);      // ← ВТОРОЙ: враги реагируют
    turn++;
}

// ❌ НЕЛЬЗЯ НАОБОРОТ!
// Враги будут реагировать на старое состояние игрока
```

Почему важен порядок:
- `afterPlayerTurn()` может изменить `player.hp` или `player.sleepTurns`
- `enemiesTurn()` должен видеть НОВОЕ состояние игрока
- Если наоборот, враги атакуют "вчерашнего" игрока

---

### 4. Chebyshev расстояние для проверки соседства

```java
// ✅ ПРАВИЛЬНО (8-направленная сетка, диагонали учитываются)
int dist = Math.max(Math.abs(x1 - x2), Math.abs(y1 - y2));
if (dist == 1) { /* враг рядом */ }

// ❌ НЕПРАВИЛЬНО (только 4 направления)
int dist = Math.abs(x1 - x2) + Math.abs(y1 - y2);  // Manhattan distance
if (dist == 1) { /* пропустит диагонали */ }
```

Когда использовать какое:
- **Chebyshev (max)** — для проверки соседства (враг рядом?)
- **Manhattan (sum)** — для видимости/хостильности (враг видит?)

В `enemiesTurn()` используем ОБОИХ:
```java
int manhattanDist = Math.abs(e.getX() - p.getX()) + 
                    Math.abs(e.getY() - p.getY());
                    
if (manhattanDist <= hostility) {
    moveEnemyTowards();  // ← враг видит игрока (Manhattan)
}

int chebyDist = Math.max(
    Math.abs(e.getX() - p.getX()),
    Math.abs(e.getY() - p.getY())
);

if (chebyDist == 1) {
    enemyAttackPlayer();  // ← враг рядом (Chebyshev)
}
```
