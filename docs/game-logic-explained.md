## ГЛАВНАЯ ИДЕЯ

Представь, что мы делаем пошаговую игру типа Dungeon Crawler:

```
┌─────────────────────────────────┐
│ ИГРОК (Player)                  │
├─────────────────────────────────┤
│ ┌─────────────────────────────┐ │
│ │ ВРАГИ (Enemies)             │ │
│ │ ├─ Вампир (VAMPIRE)         │ │
│ │ ├─ Зомби (ZOMBIE)           │ │
│ │ └─ Привидение (GHOST)       │ │
│ └─────────────────────────────┘ │
│                                 │
│ КАРТА 10x10 клеток              │
└─────────────────────────────────┘

ПРАВИЛА:
1. Игрок ходит первый (нажимает кнопку)
2. Враги ходят в ответ
3. Когда они рядом — идёт бой
4. Раунд за раундом...
```

**Это всё находится в классе `GameState`** — этот класс помнит ВСЁ:
- Где находится игрок (координаты x, y)
- Где находятся враги (список врагов)
- Сколько HP у каждого
- Что в инвентаре
- И много ещё чего

## ЧТО ТАКОЕ "STATE"

**STATE** (состояние) — это "слепок" того, как выглядит игра в данный момент.

### Пример:

```
РАУНД 1:
┌─────────────────┐
│ Player (5,5)    │
│ HP: 100/100     │
│                 │
│ Vampire (5,4)   │
│ HP: 25/25       │
│                 │
│ Zombie (6,5)    │
│ HP: 30/30       │
└─────────────────┘

РАУНД 2:
┌─────────────────┐
│ Player (5,5)    │
│ HP: 92/100  ↙   │  (получил урон)
│                 │
│ Vampire (5,5)   │  (переместился)
│ HP: 25/25       │  (первый удар был заблокирован)
│                 │
│ Zombie (6,5)    │
│ HP: 30/30       │
└─────────────────┘
```

Каждое изменение — это изменение **STATE** (состояния).

**В коде это выглядит так:**

```java
public class GameState {
    // Игрок
    private Player player;              // ← объект игрока
    
    // Враги
    private List<Enemy> enemies;        // ← список враагов
    
    // Инвентарь
    private String[] inventory;         // ← что в кармане
    
    // Координаты (синхронизируем с player)
    private int playerX, playerY;
    
    // Размер карты
    private int width, height;
}
```

## СИСТЕМА КОМАНД (COMMAND)

Когда ты нажимаешь кнопку (стрелка вверх, ждать и т.д.), создаётся **КОМАНДА**.

### Что такое Command?

Это **запрос на действие**. Как письмо, которое ты отправляешь:

```
ПИСЬМО-КОМАНДА:
┌──────────────────┐
│ Тип: MOVE        │
│ Параметр: UP     │
└──────────────────┘

ПИСЬМО-КОМАНДА:
┌──────────────────┐
│ Тип: WAIT        │
└──────────────────┘

ПИСЬМО-КОМАНДА:
┌──────────────────┐
│ Тип: ATTACK      │
│ Параметр: ENEMY  │
└──────────────────┘
```

**В коде:**

```java
public sealed interface Command permits
    Command.Move,
    Command.Wait,
    Command.OpenInventory,
    // ...
{
    // КОМАНДА 1: Переместиться
    record Move(Direction direction) implements Command {}
    
    // КОМАНДА 2: Подождать
    record Wait() implements Command {}
    
    // КОМАНДА 3: Открыть инвентарь
    record OpenInventory() implements Command {}
}
```

### Как создаётся команда?

```java
// Игрок нажимает СТРЕЛКУ ВВЕРХ
User.pressKey(UP)
  ↓
KeyMapper.processInput(UP)
  ↓
return new Command.Move(Direction.UP)  ← ВОТ КОМАНДА!
  ↓
DefaultGameEngine.step(command)  ← Игра обрабатывает команду
```

## КАК ПРОИСХОДИТ ОДИН ХОД

### Визуально:

```
НАЧАЛО РАУНДА 1
│
├─ 1️⃣ ИГРОК ДЕЙСТВУЕТ
│  │
│  └─ Command.Move(UP)
│     ↓
│     gameState.tryMovePlayer(UP)
│     ├─ Проверить, куда ходим
│     ├─ Если враг на пути → атаковать его
│     └─ return true (ход потратился)
│
├─ 2️⃣ ОБНОВИТЬ ИГРОКА
│  │
│  └─ gameState.afterPlayerTurn()
│     └─ player.tickSleep()  ← если был сон, уменьшить
│
├─ 3️⃣ ВРАГИ ХОДЯТ
│  │
│  └─ gameState.enemiesTurn()
│     ├─ Для каждого врага:
│     │  ├─ Видит ли враг игрока?
│     │  │  ├─ ДА → идти в сторону игрока
│     │  │  └─ НЕТ → идти случайно
│     │  │
│     │  └─ Враг рядом с игроком?
│     │     └─ ДА → атаковать!
│     │
│     └─ Удалить мёртвых врагов
│
├─ 4️⃣ СЧЁТЧИК РАУНДОВ
│  │
│  └─ turn++  (0 → 1 → 2 → 3 ...)
│
└─ 5️⃣ ВЕРНУТЬ РЕЗУЛЬТАТ
   │
   └─ return GameSnapshot(...)
      └─ Отправить на экран: "Player at (5,5), HP 92/100"

КОНЕЦ РАУНДА 1 → НАЧАЛО РАУНДА 2
```

### В коде:

```java
public GameSnapshot step(Command cmd) {
    List<String> log = new ArrayList<>();
    boolean playerActionUsedTurn = false;
    
    // 1️⃣ Обработать команду игрока
    if (cmd instanceof Command.Move m) {
        playerActionUsedTurn = state.tryMovePlayer(m.direction(), log);
    }
    else if (cmd instanceof Command.Wait) {
        playerActionUsedTurn = true;
    }
    
    // 2️⃣ 3️⃣ 4️⃣ Если ход потратился, враги ходят
    if (playerActionUsedTurn) {
        state.afterPlayerTurn(log);      // 2️⃣
        state.enemiesTurn(log);          // 3️⃣
        turn++;                          // 4️⃣
    }
    
    // 5️⃣ Вернуть результат
    return new GameSnapshot(
        state.playerX(),
        state.playerY(),
        (int) turn,
        log
    );
}
```

## ВРАГИ И ИХ СПОСОБНОСТИ

### Что такое враг?

Враг — это **объект с параметрами**:

```java
public class Enemy {
    private Type type;           // ZOMBIE, VAMPIRE, GHOST...
    private int x, y;            // координаты
    private int hp;              // здоровье
    private EnemyStats stats;    // статистика
    private EnemySpecial special; // спец. способность
}
```

### Параметры врага (stats)

```
ZOMBIE (уровень 1):
├─ HP: 30
├─ STR (Сила): 6
├─ DEX (Ловкость): 4
└─ Hostility (Дружелюбие): 5

VAMPIRE (уровень 1):
├─ HP: 25
├─ STR: 7
├─ DEX: 12  ← очень ловкий!
└─ Hostility: 8

GHOST (уровень 1):
├─ HP: 8   ← слабый!
├─ STR: 3
├─ DEX: 14 ← быстрый!
└─ Hostility: 3
```

**STR** — сколько урона наносит враг  
**DEX** — насколько хорошо он избегает ударов  
**Hostility** — как далеко он видит игрока  

### Спец. способности

Некоторые враги имеют **особые способности**:

```
ВАМПИР:
├─ FirstHitIgnored ← первый удар игрока не наносит урон!
└─ VampireDrain ← вампир пьёт кровь (восстанавливает HP)

МАГИЧЕСКИЙ ЗМЕЙ:
└─ SleepOnHit ← может усыпить игрока на 2 хода

ПРИВИДЕНИЕ:
└─ (пока нет, можно добавить)
```

## FirstHitIgnored — САМАЯ ИНТЕРЕСНАЯ МЕХАНИКА

### Что это?

Вампир имеет способность **заблокировать первый удар игрока**!

### Как это работает:

```
РАУНД 1: Первая атака игрока на вампира

Игрок наносит 15 урона
  ↓
Вампир проверяет: "Это мой первый раз, когда меня атакуют?"
  ├─ ДА! → Заблокировать весь урон (вернуть 0)
  └─ FirstHitIgnored.firstHitIgnored = false  ← помнит, что уже был
  ↓
Вампир получает 0 урона
  ↓
Вампир остался на 25 HP

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

РАУНД 2: Вторая атака игрока на вампира

Игрок наносит 14 урона
  ↓
Вампир проверяет: "Это мой первый раз?"
  ├─ НЕТ! (уже был) → Пропустить блокировку
  └─ Вернуть нормальный урон (14)
  ↓
Вампир получает 14 урона
  ↓
Вампир остался на 11 HP ← УЙ!
```

### Как это выглядит в коде:

```java
public final class FirstHitIgnoredSpecial implements EnemySpecial {
    private boolean firstHitIgnored = true;  // флаг состояния
    
    @Override
    public int onBeforeTakeDamage(Enemy enemy, int incomingDamage) {
        if (firstHitIgnored) {
            // Первый раз! Заблокировать
            firstHitIgnored = false;  // запомнить, что уже был
            return 0;  // ← БЕЗ УРОНА!
        }
        // Не первый раз
        return incomingDamage;  // ← нормальный урон
    }
}
```

### Когда это вызывается?

```java
// Когда игрок атакует вампира:
Enemy vampire = new Enemy(VAMPIRE, 1, 5, 4);

// Игрок наносит урон
int damage = 15;

// ВАЖНО! Сначала спрашиваем специальность:
int actualDamage = vampire.getSpecial()
    .onBeforeTakeDamage(vampire, damage);
    // ↓ вызывает FirstHitIgnoredSpecial.onBeforeTakeDamage()
    // ↓ возвращает 0 (в первый раз)

// Потом применяем урон:
vampire.takeDamage(actualDamage);
// vampire.hp = Math.max(0, 25 - 0) = 25  ← не изменилось!
```

## КЛЮЧЕВЫЕ МОМЕНТЫ ДЛЯ ЗАПОМИНАНИЯ

### 1. **GameState — это сердце игры**

Туда мы кладём:
- Игрока (Player)
- Врагов (List<Enemy>)
- Инвентарь
- Размер карты

И из неё доходят ВСЕ методы игры.

### 2. **Command — это запрос**

Когда игрок нажимает кнопку → создаём Command → отправляем в engine.

### 3. **Step — это один раунд**

```
engine.step(command)  ← один раунд
  ├─ Игрок действует
  ├─ Враги действуют
  └─ Вернуть новое состояние
```

### 4. **Порядок в enemiesTurn ВАЖЕН**

```
1️⃣ Враг применяет спец. эффекты    (e.tick())
2️⃣ Враг проверяет видимость       (dist <= hostility)
3️⃣ Враг движется или атакует      (moveTowards или attack)
4️⃣ Проверяем, не помер ли враг    (e.isAlive())
```

### 5. **EnemySpecial — это крючки (hooks)**

Враг имеет три момента, когда может что-то сделать:

```java
onBeforeTakeDamage()   // ← Перед получением урона
onAfterEnemyHit()      // ← После того, как враг атаковал
onTick()               // ← Каждый раунд (эффекты)
```

FirstHitIgnored использует первый крючок и блокирует урон.

## ВОПРОСЫ ДЛЯ ПРОВЕРКИ ПОНИМАНИЯ

Если ты понял объяснение, ответь на эти вопросы:

1. **Что такое GameState?**
   <details>
   <summary>Ответ</summary>
   Класс, который хранит ВСЁ состояние игры: игрока, врагов, инвентарь, размер карты и методы для их управления.
   </details>

2. **Когда создаётся Command?**
   <details>
   <summary>Ответ</summary>
   Когда игрок нажимает кнопку. KeyMapper преобразует нажатие в Command.
   </details>

3. **Что происходит в enemiesTurn?**
   <details>
   <summary>Ответ</summary>
   Враги проверяют видимость игрока, движутся или атакуют, применяют спец. способности.
   </details>

4. **Как FirstHitIgnored блокирует урон?**
   <details>
   <summary>Ответ</summary>
   Враг имеет флаг firstHitIgnored. Когда игрок атакует в первый раз, специальность возвращает 0 вместо урона, и флаг становится false.
   </details>

5. **Почему afterPlayerTurn вызывается ДО enemiesTurn?**
   <details>
   <summary>Ответ</summary>
   Потому что враги должны реагировать на НОВОЕ состояние игрока. Если наоборот, враги не будут знать о новом состоянии.
   </details>
