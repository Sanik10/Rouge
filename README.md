# Rogue-like Dungeon Crawler

## Краткое описание

Консольный roguelike в духе классической Rogue (1980), реализованный на Java 21 с использованием терминального UI на базе библиотеки Lanterna. Игра генерирует 21 уровень подземелья в виде сетки из 9 комнат, соединённых коридорами. Бой и передвижение пошаговые: игрок исследует уровни, сражается с разными типами противников, собирает предметы и сокровища, развивает характеристики персонажа. Проект построен на многослойной архитектуре (domain / presentation / datalayer), поддерживает сохранение/загрузку прогресса и таблицу рекордов в формате JSON, а также включает дополнительный 3D‑режим на основе ray casting.

---

## Возможности

- Пошаговый roguelike в терминале.
- 21 процедурно генерируемый уровень подземелья.
- Каждое подземелье — 3×3 комнаты, соединённые коридорами в связный граф.
- 5 базовых типов противников с уникальным поведением и особыми эффектами.
- Система характеристик персонажа: здоровье, максимальное здоровье, сила, ловкость.
- Предметы:
  - сокровища;
  - еда;
  - эликсиры;
  - свитки;
  - оружие.
- Инвентарь с автоматическим подбором предметов и ограничением по количеству слотов.
- Пошаговая боевая система с вероятностью попадания и модификаторами от оружия/эффектов.
- «Туман войны» и поле зрения на основе ray casting и алгоритма Брезенхэма.
- Два режима отображения:
  - классическое 2D (вид сверху);
  - псевдо‑3D от первого лица.
- Сохранение и загрузка прогресса в `save.json`.
- Таблица рекордов в `leaderboard.json` с сортировкой по количеству сокровищ.

## Архитектура

Проект разделён на три основных слоя:

### 1. `app` — точка входа и инициализация

- `ru.crawl.app.Main` — стартовый класс приложения.
- `ru.crawl.app.Bootstrap` — конфигурация и связывание слоёв:
  - инициализация `GameEngine`;
  - создание представлений (2D/3D);
  - настройка репозиториев сохранений и лидерборда.

### 2. `domain` — бизнес‑логика и модель

Не зависит от UI и конкретного способа хранения данных.

- `ru.crawl.domain.model`  
  Основные игровые сущности и логика:
  - `Player` — игрок и его характеристики.
  - `Enemy`, `EnemyStats`, `EnemyStatsFactory` — противники и их параметры.
  - `EnemySpecial`, `CompositeEnemySpecial`, `FirstHitIgnoredSpecial`, `SleepOnHitSpecial`, `VampireDrainMaxHpSpecial`, `NoSpecial` — система особых способностей врагов.
  - `Item`, `ScrollEffect`, `Inventory` — предметы и инвентарь.
  - `GameState` — текущее состояние игры (уровень, карта, акторы).
  - `GameStats` — статистика прохождения (убитые враги, использованные предметы и т.д.).
  - `Combat` — боевая логика (расчёт попаданий, урона и смертей).

- `ru.crawl.domain.generation`  
  Генерация уровней:
  - `LevelGenerator` — построение уровня из 9 комнат и соединяющих их коридоров; гарантия связности.
  - `rogue.Room`, `RoomGenerator`, `SimpleRoomGenerator` — генерация геометрии комнат.
  - `rogue.CorridorHorizontal`, `CorridorVertical`, генераторы коридоров — построение путей между комнатами.

- `ru.crawl.domain.usecase`  
  Игровой движок и команды:
  - `GameEngine`, `DefaultGameEngine` — основной цикл обработки команд и изменение `GameState`.
  - `GameSnapshot` — снимок состояния игры (удобен для сохранения и отката).
  - `Command` — абстракция всех действий игрока (движение, бой, использование предметов, открытие меню, сохранение игры, переход по лестнице, переключение 3D‑режима и др.).

### 3. `presentation` — пользовательский интерфейс

Работает поверх `domain`, не содержит бизнес‑логики.

- `ru.crawl.presentation.input`
  - `UserInput` — модель пользовательского ввода.
  - `KeyMapper` — сопоставление нажатий клавиш с командами `Command` для `GameEngine`.

- `ru.crawl.presentation.view`
  - `View` — интерфейс представления.
  - `LanternaView` — основное 2D‑представление карты, интерфейса и тумана войны.
  - `LanternaView3d` — 3D‑представление от первого лица.
  - `Raycaster` — реализация ray casting для расчёта видимых сегментов стен.
  - `FogUtils` — логика «тумана войны» и видимости.
  - `AsciiSprite`, `EnemySprites`, `ItemSprites` — наборы символов и спрайтов для отрисовки сущностей.

- `ru.crawl.presentation.presenter`
  - `GamePresenter` — связывает `GameEngine`, `View` и `UserInput`, управляет состояниями (игра, меню, таблица рекордов и т.п.).
  - `presenter.ui.*` — отдельные экраны:
    - `StartScreen`, `StartMenuAction` — стартовое меню;
    - `LeaderboardsScreen` — просмотр таблицы рекордов;
    - `FinalScreen`, `FinishResult`, `FinishMenuAction` — финальный экран и выбор действий по окончании игры;
    - `RougeBackground` / `BannerType` — оформление и заставки.

### 4. `datalayer` — доступ к данным

Отвечает за чтение и запись JSON‑файлов.

- `ru.crawl.datalayer.json.JsonSaveRepository`
  - Сохранение и загрузка текущей игровой сессии в `save.json`.
- `ru.crawl.datalayer.json.JsonLeaderboardRepository`
  - Работа с таблицей рекордов в `leaderboard.json`.
- `SaveGameMapper`
  - Преобразование внутренних моделей `domain` в сериализуемые DTO и обратно.
- `saveData.*`
  - DTO для сериализации:
    - `SaveGame`, `SavePlayer`, `SaveEnemy`, `SaveInventory`, `SaveItem`, `SaveScrollEffect`, `SaveStats`.
- `leaderbordData.Leaderboard`
  - Модель и контейнер для записей таблицы рекордов.

Такое разделение облегчает модификацию и тестирование отдельных частей (например, можно заменить UI или способ хранения данных, не трогая бизнес‑логику).

## Игровая механика

### Уровни

- 21 последовательно проходящийся уровень.
- Каждый уровень:
  - логически разделён на 9 секций (3×3);
  - в каждой секции случайным образом генерируется комната с произвольным размером и расположением;
  - комнаты соединены коридорами; генерируется связный граф без «висящих» областей.
- Для уровня выделяются:
  - стартовая комната (старт игрока, без противников);
  - конечная комната (переход на следующий уровень).
- С усложнением уровней:
  - возрастает количество и сила противников;
  - уменьшается количество полезных предметов;
  - увеличивается количество сокровищ.

### Персонаж

- Характеристики:
  - **здоровье** — при 0 и ниже игра заканчивается;
  - **максимальное здоровье** — верхняя граница восстановления;
  - **сила** — базовый урон и вклад в урон с оружием;
  - **ловкость** — влияет на вероятность попадания.
- Возможности:
  - перемещение по комнатам и коридорам;
  - автоматический подъём предметов (при наличии места в инвентаре);
  - использование еды, эликсиров, свитков и оружия;
  - управление инвентарём и смена экипировки.
- При достижении лестницы в конечной комнате происходит переход на следующий уровень.

### Противники

- Имеют характеристики: здоровье, сила, ловкость, враждебность.
- Враждебность определяет расстояние, с которого начинается преследование игрока.
- Поддерживаются разные типы врагов с уникальным поведением:
  - зомби;
  - вампиры (первый удар по ним всегда промах, могут отнимать максимум здоровья);
  - привидения (телепортируются, периодически невидимы);
  - огры (большой урон и здоровье, ходят по две клетки, отдыхают после атаки);
  - змеи‑маги (очень высокая ловкость, ходят по диагонали, могут усыплять).
- При начале преследования все монстры стремятся к игроку по кратчайшему пути по соседним клеткам.  
  Если путь отсутствует, продолжают двигаться по своему паттерну.

### Боевая система

- Пошаговая модель:
  - каждое действие игрока — один ход;
  - после хода игрока отрабатывают действия противников.
- Бой инициируется при попытке зайти в клетку с противником.
- Удар рассчитывается в несколько этапов:
  1. Проверка попадания (случайная величина, зависящая от ловкости атакующего и цели).
  2. Расчёт урона (сила + модификаторы оружия/эффектов).
  3. Применение урона и возможная смерть.
- При победе над противником игрок получает сокровища; их количество зависит от характеристик врага.

### Предметы и инвентарь

- Типы предметов:
  - **сокровища** — влияют на итоговый рейтинг и таблицу рекордов;
  - **еда** — восстанавливает здоровье;
  - **эликсиры** — временно повышают характеристики;
  - **свитки** — постоянно повышают характеристики;
  - **оружие** — изменяет формулу урона.
- Рюкзак:
  - хранит все типы предметов;
  - ограничение — до 9 предметов каждого типа (сокровища копятся в общей «ячейке»).
- При использовании:
  - еда, эликсиры и свитки расходуются;
  - оружие может быть экипировано/снято, при смене может падать на соседнюю клетку.

### Туман войны и поле зрения

- Неизведанные области не отображаются.
- Просмотренные, но покинутые, комнаты и коридоры отображаются схематично (например, только стены).
- В комнате с игроком и в области прямой видимости показываются:
  - стены и пол;
  - враги;
  - предметы.
- Видимость рассчитывается с помощью ray casting и алгоритма Брезенхэма.

## Управление

Управление осуществляется с клавиатуры (конкретные клавиши задаются в `KeyMapper`):

- **Перемещение**:
  - В 2D‑режиме: стандартно `W`, `A`, `S`, `D` — движение по карте.
  - В 3D‑режиме:
    - `W` — шаг вперёд;
    - `S` — шаг назад;
    - `A` — поворот влево;
    - `D` — поворот вправо.

- **Инвентарь и предметы**:
  - Открытие меню инвентаря и подменю по типам предметов.
  - Выбор предмета по номеру (1–9) и подтверждение действия.
  - Для оружия предусмотрена возможность снять оружие, не выбрасывая его из инвентаря.

- **Режимы и системные действия**:
  - Переключение между 2D‑ и 3D‑режимами.
  - Сохранение игры.
  - Выход в главное меню / завершение приложения.

Актуальную раскладку клавиш можно скорректировать в `ru.crawl.presentation.input.KeyMapper`.

## Сохранения и таблица рекордов

Слой `datalayer` реализует файловое хранилище прогресса:

- **`save.json`**
  - Хранит состояние последней игровой сессии:
    - текущий уровень и карта;
    - положение игрока и врагов;
    - содержимое инвентаря и экипировка;
    - характеристики и временные эффекты;
    - статистика прохождения.
  - После прохождения каждого уровня состояние автоматически сохраняется.
  - При следующем запуске игру можно продолжить с последнего сохранения.

- **`leaderboard.json`**
  - Содержит историю всех прохождений (успешных и неуспешных).
  - Для каждой попытки фиксируются:
    - достигнутый уровень;
    - количество собранных сокровищ;
    - вспомогательная статистика (убитые враги, использованные предметы и т.п.).
  - В интерфейсе доступна таблица рекордов, отсортированная по количеству сокровищ.

## Запуск

**Требования:**

- Java 21+
- Gradle (можно использовать встроенный wrapper)

**Сборка и запуск из командной строки:**

```bash
# Сборка
./gradlew build

# Запуск
./gradlew run
```

Либо:

1. Открыть проект в IntelliJ IDEA / другом IDE.
2. Импортировать как Gradle‑проект.
3. Запустить класс `ru.crawl.app.Main`.
